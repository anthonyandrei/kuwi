# Use Expo for the PWA client

Accepted: 2026-11-07

Use Expo, React Native Web, Expo Router, and Reanimated for Kuwi's PWA. Anthony
accepted this stack because it matches Tarsi's shipped web client and can
express the recovered layout and motion rules. PWA installation, offline
startup, and browser storage still require explicit implementation. This does
not commit to native delivery or establish permission to reuse Tarsi's code.
